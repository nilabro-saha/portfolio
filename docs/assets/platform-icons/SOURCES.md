# Platform icons

Original platform assets are stored locally and displayed as decorative 18px icons beside text labels. The source brands retain their trademarks.

- YouTube: https://www.youtube.com/favicon.ico
- GitHub: https://github.githubassets.com/favicons/favicon.svg
- Zenodo: https://zenodo.org/static/favicon.ico (PNG bytes; stored as zenodo.png)
- Springer: https://link.springer.com/oscar-static/img/favicons/darwin/favicon-de0c289efe.ico
- LinkedIn: https://www.linkedin.com/favicon.ico
- ORCID: https://orcid.org/assets/vectors/orcid.logo.icon.svg
- Google Drive: https://drive.google.com/favicon.ico
- Email: original envelope SVG using simple geometric paths.

- Oracle: https://www.oracle.com/asset/web/favicons/favicon-32.png (used beside the current role in the introduction).
