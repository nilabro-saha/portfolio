# Portfolio typeface

Exo 2 variable, Latin subset (weights 100–900), is self-hosted for website text except the Playfair Display hello title and section headings and Inter arrows. Existing sizes and weights are preserved; position rows use weight 600. Helvetica, Arial, and generic sans-serif provide fallback glyphs. Text embedded in images retains its original appearance.

- Family and license: https://github.com/google/fonts/tree/main/ofl/exo2
- WOFF2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYoK-4W4nIp.woff2
- Distribution: https://fonts.googleapis.com/css2?family=Exo+2:wght@100..900&display=swap
- License: Exo2-OFL.txt

Playfair Display variable, Latin subset (weights 400–900), is self-hosted for the hello title and section headings, with Georgia and serif fallbacks.

The existing self-hosted InterVariable.woff2 is used for northeast and southeast arrows. Its license is OFL.txt.
